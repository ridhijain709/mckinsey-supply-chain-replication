# Glossary — Standardized Terminology

| Term | Definition |
|:-----|:-----------|
| **AOV** | Average Order Value — mean basket size in INR per completed order |
| **Dark Store** | Micro-warehouse (800–2,000 sq.ft) stocking 3,000–5,000 SKUs for hyper-local fulfillment |
| **Contribution Margin (CM)** | Revenue minus variable costs per order; does not include fixed cost absorption |
| **EBITDA** | Earnings Before Interest, Tax, Depreciation, and Amortization — monthly store-level profitability measure |
| **Take Rate** | Blended effective revenue rate = Commission % + Convenience Fee + Ad Revenue, expressed as % of AOV |
| **Break-Even Density** | Minimum orders/day required for monthly contribution margin to cover total fixed costs |
| **GMV** | Gross Merchandise Value — total transaction value processed through the platform |
| **Fill Rate** | % of SKUs available when ordered (not stockout) |
| **Pick Accuracy** | % of orders packed correctly with zero wrong/missing items |
| **On-Time Delivery** | % of orders delivered within promised time window (typically 10–15 minutes) |
| **Batching Ratio** | Average number of orders fulfilled per rider trip (1.2× = 20% of trips are dual-order deliveries) |
| **Swiggy One** | Swiggy's subscription product; members get free delivery, priority access, and exclusive discounts |
| **SCOR** | Supply Chain Operations Reference — industry-standard framework for operational diagnostics |
| **CAC** | Customer Acquisition Cost — total marketing spend divided by new customers acquired |
| **Monte Carlo** | Statistical simulation technique using random sampling to model probability distributions of outcomes |
| **P5/P50/P95** | 5th/50th/95th percentile outcomes from Monte Carlo distribution (downside/median/upside) |
| **Capex Amortization** | Spreading one-time capital expenditure (dark store fit-out) over useful life (36 months) |
