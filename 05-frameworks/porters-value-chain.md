# Porter's Value Chain — Swiggy Instamart Q-Commerce

## Primary Activities

| Activity | Key Operations | Competitive Advantage | Weakness / Gap |
|:---------|:--------------|:---------------------|:---------------|
| **Inbound Logistics** | Vendor procurement, dark store replenishment, cold-chain management | Scale-based vendor terms for Top 200 SKUs | Fill rate 84% (below 95% target); Tier 2 vendor unreliability |
| **Operations** | Order picking (2–3 min), packing, quality check, temperature control | Pick accuracy 96.2%; near-automation via slotting optimization | Picking delay = #3 cause of late delivery (22% of failures) |
| **Outbound Logistics** | Rider dispatch, last-mile delivery, zone routing, batching | Proprietary dispatch algorithm; 12-min avg. delivery | On-time rate 81% (target 91%); batching ratio only 1.2× |
| **Marketing & Sales** | Hyperlocal ads, in-app promotions, Swiggy One subscription | 40M+ Swiggy app users; cross-selling from food delivery | Subscriber penetration only ~8% on Instamart (vs potential 18%+) |
| **Customer Service** | Refund processing, wrong-item resolution, rating management | Same-app resolution; automated refund for speed | 3.8% return rate (target 2%); fresh produce quality complaints |

## Support Activities

| Activity | Role in Q-Commerce | Strategic Strength |
|:---------|:-------------------|:------------------|
| **Firm Infrastructure** | Regulatory compliance (FSSAI, FDI), financial planning, dark store network governance | DRHP filing demonstrates institutional-grade governance |
| **HR & Talent Management** | Gig rider fleet management, dark store operations hiring, tech talent | Rider incentive programs; ongoing challenge: gig worker retention |
| **Technology Development** | Demand forecasting, route optimization, in-app recommendation, fraud detection | Proprietary ML stack; forecast accuracy gap is primary tech debt |
| **Procurement** | Vendor SLA management, category buying, private label development | Scale purchasing power; private label = AOV and margin lever |

## Where Competitive Advantage is Created

```
MARGIN CREATION MAP:
  
  HIGH IMPACT ┌─────────────────────────────────────────┐
              │  ★ Dispatch Algorithm (reduce cost/order) │
              │  ★ Swiggy One (reduce CAC, raise AOV)    │
              │  ★ Demand Forecasting (reduce waste)      │
  LOW IMPACT  └─────────────────────────────────────────┘
              EASY TO EXECUTE ──────── HARD TO EXECUTE
```

**Primary margin lever:** Technology (dispatch, forecasting) + Subscription (AOV × frequency)  
**Structural moat:** Density dominance in micro-catchments (2km radius) — hard to displace once achieved
